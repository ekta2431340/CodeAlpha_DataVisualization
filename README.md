# Netflix Data Visualization Dashboard

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The dashboard visualizes Netflix Movies and TV Shows data using Python and Streamlit. Various charts and graphs are used to identify trends, patterns, and insights from the dataset.

## Features

* Movies vs TV Shows Analysis
* Top 10 Countries by Content
* Ratings Distribution
* Release Year Trends
* Interactive Data Exploration

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Streamlit

## Dataset

Netflix Movies and TV Shows Dataset
